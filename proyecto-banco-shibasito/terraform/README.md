# Terraform para el Proyecto Shibasito

Este directorio contiene la configuración de Terraform para validar la infraestructura del proyecto Shibasito.

## Uso

Para utilizar Terraform, ejecuta los siguientes comandos desde la raíz del proyecto:

- `make terraform-init`: Inicializa Terraform.
- `make terraform-validate`: Valida la configuración de Terraform.
- `make terraform-plan`: Crea un plan de ejecución de Terraform.
- `make terraform-apply`: Aplica la configuración de Terraform.
