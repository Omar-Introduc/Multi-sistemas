
# Chapter 1: Giving Computers the Ability to Learn from Data
Verifica tu versión de Python:

### Abre una terminal o línea de comandos.
Escribe python --version y presiona Enter. Esto mostrará la versión de Python instalada en tu sistema. Asegúrate de tener Python 3.7.0 o una versión más reciente.

### Instala las bibliotecas:
Abre la terminal o línea de comandos.
Para instalar las bibliotecas, utiliza el administrador de paquetes pip. Ejecuta los siguientes comandos uno por uno:

```
pip install numpy
pip install scipy
pip install scikit-learn
pip install matplotlib
pip install pandas
```
